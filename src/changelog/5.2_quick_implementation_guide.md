## Executive Summary

**Problem:** Current IR extraction has gaps causing data loss and unresolved references
- Navigation URLs hidden in method bodies → not extracted
- Method parameters → not mapped to step inputs
- Method calls → not followed to definitions → data incomplete

**Solution:** 4-week integration plan to add missing analysis layers
1. **Week 1:** Build shared analyzers (CallGraph, DataFlow)
2. **Week 2:** Enhance extractors to use analyzer
3. **Week 3:** Add validation layer
4. **Week 4:** Test & document

**Outcome:** Zero orphaned references, 100% data completeness

---

## Quick Reference: What Needs to Happen

### Current Gaps

| Category | Problem | Impact | Solution |
|----------|---------|--------|----------|
| **Method Traversal** | ActionMapper can't see inside method bodies | Navigation URLs not extracted | Integrate CallGraphBuilder to resolve method bodies |
| **Parameter Binding** | Method parameters not traced to call site | Step inputs null | Add DataFlowAnalyzer parameter mapping |
| **Target Resolution** | Unresolved target_name_id → orphaned refs | "toProducts" targetId missing from targets.json | Add Strategy 3 (CallGraph resolution) in StepEnricher |
| **Navigation Extraction** | driver.get() calls missed | Only locators captured, no URLs | Enhance LocatorExtractor to find driver.get() |
| **Validation** | No detection of missing data | Issues only found in manual review | Create CompletenessValidator |

## Next: Get Started!

**Start with Week 1, Task 1:**

```python
# File: src/analysis/call_graph.py
# Add this method:

def resolve_method_body(self, class_name: str, method_name: str) -> List[ASTNode]:
    """
    Return all statements in the body of a method.
    
    Example:
        body = call_graph.resolve_method_body("ProductPage", "navigateToProducts")
        → [ASTNode(driver.get(...)), ASTNode(waitFor...)]
    """
    method_def = self.method_defs.get((class_name, method_name))
    if method_def:
        return method_def.children  # Method body statements
    return []
```

Then write a test (src/tests/test_call_graph_enhanced.py):

```python
def test_resolve_method_body():
    # Given a method definition
    # When resolving its body
    # Then get all statements in method
    body = call_graph.resolve_method_body("ProductPage", "navigateToProducts")
    assert len(body) > 0
    assert any(self._is_driver_get_call(stmt) for stmt in body)
```
