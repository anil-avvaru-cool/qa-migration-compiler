# 1.1 AST Enhancements

Summary of changes:

- Added `CrossASTIndex` for cross-file AST lookup.
- Implemented `TypeHierarchyResolver` to model class inheritance and MRO-like linearization.
- Added `CallGraphBuilder` for conservative call graph construction.
- Added `DataFlowAnalyzer` for locating locator initializers across fields/variables.
- Added `WrapperExpander` to detect and expand delegating wrapper chains (multi-level).
- Unit tests added covering the new modules.

Notes:
- The implementations are conservative and designed to integrate with the existing `ASTNode` model.
- Future improvements: tighter integration with Java parser node shapes for more precise parent/type resolution.
